## How to make the website live (GitHub Pages)
1. Open the repository: https://github.com/kaursameeta-alt/SEO-Copywriting-Specialist
2. Go to **Settings** → **Pages** (left sidebar)
3. Under **Source**, choose **Deploy from a branch**
4. Select branch **main** and folder **/ (root)**
5. Click **Save**

Wait 1–2 minutes. Your public link will be ready:
https://kaursameeta-alt.github.io/SEO-Copywriting-Specialist/

You can then add this link to your Fiverr profile or gig descriptions.
